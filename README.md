# Hotel Chain Management System

## Project Overview

The Hotel Chain Management System is a SQL-based database project designed to manage and organize hotel operations efficiently. The system stores and manages information related to hotels, rooms, guests, bookings, employees, and payments.

The project demonstrates the use of relational database concepts and SQL queries to retrieve, update, and analyze hotel management data.

## Objectives

- Manage hotel and room information.
- Store and manage guest details.
- Handle room bookings and reservations.
- Maintain employee records.
- Manage payment-related information.
- Retrieve useful information using SQL queries.
- Maintain data consistency using database constraints.

## Technologies Used

- SQL
- MySQL
- Relational Database Management System (RDBMS)

## Database Entities

The database contains tables for managing different aspects of the hotel chain, including:

- Hotels

- Employees
